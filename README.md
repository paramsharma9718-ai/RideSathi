# RideSathi 🚗

**RideSathi — Making Every Journey Easier**

## 📌 About the Project
RideSathi is a ride-sharing web application designed to help users find and share rides conveniently. The goal is to make daily travel more accessible, affordable, and collaborative.

## 🎯 Objectives
- Connect people travelling on similar routes.
- Help users share travel costs.
- Provide a simple and user-friendly interface.
- Make everyday commuting easier.

## ✨ Planned Features
- User Registration and Login
- Create and Search Rides
- View Ride Details
- Send Ride Requests
- Manage Bookings
- User Profile Management

## 🛠️ Technologies

- Java Servlets and JSP
- HTML and CSS
